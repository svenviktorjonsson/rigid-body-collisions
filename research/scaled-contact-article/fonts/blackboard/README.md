# Blackboard matrix digits

The three Type 1 BBOLD fonts are copied unchanged from https://ctan.org/pkg/bbold-type1 (CTAN archive https://mirrors.ctan.org/fonts/bbold-type1.zip). Only double-struck matrix-block digits are selected; the existing AMS double-struck inertia I is retained.

This repacking of Type1 version of BBOLD font from Y&Y.

Only 10, 7 and 5pt sizes were provided by Y&Y, other sizes in Ubbold.fd will be scaled from nearest size.

The files are Copyright 2007 TeX Users Group, with license:

  "You may freely use, modify and/or distribute this file."

TFM metrics were generated with afm2tfm from the corresponding AFM files in that archive. build.sh supplies local font search paths, so no extra system font package is required.
