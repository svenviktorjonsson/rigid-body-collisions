# Independent native fallback review

The reviewed seven helpers are the immutable files under `research/active-direct/final`. This review edits none of them. `provenance.json` and `review-source.zip` pin the exact helper and shared source used to build the controls, compiler flags, binary and linked LAPACK/BLAS/Bullet libraries.

Sixteen independent controls pass: analytical sticking and isotropic sliding; malformed matrix/vector/dependency dimensions, dependency index and parent chains; unsupported negative dependency marker; mismatched tangent friction coefficients; negative upper bound; nonfinite matrix/RHS; invalid tolerance; wrapper work-limit rejection; a valid system with an impossible pressure upper bound after actual bounded search; and zero-work rejection at the public guide/More helpers. Every rejected call preserves the caller's impulse vector. `checks.cpp` is the executable control source and `checks.txt` is its receipt.

The review initially found missing public entry checks at the homotopy and More helpers. The author corrected them through `restart_validate.h`: dimensions, finite inputs, dependency range/parent invariants, two tangents per normal, isotropic friction, normal mobility, upper bounds and positive finite tolerance now reject unsupported calls before array access. Work-limit checks reject zero/negative supplied limits.

All success paths use local numerical candidates and require the original full circular projection residual, normal impulse bounds and finite frozen-system passivity bound. The normal negative-roundoff clipping is followed by re-evaluation of the full gate. Numerical friction continuation, damping and pressure relocation do not alter the applied material: only an original-law accepted final impulse reaches the caller. LAPACK nonconvergence rejects a search step. The spectral workspace request is finite and within integer allocation range.

Two integration conditions remain explicit rather than implied. First, each solve receives fresh statistics; its scalar counts are aggregated afterward. Several search branches use their statistics to compute remaining work, so reusing accumulated nested statistics would falsely consume future solve budgets. The parent confirmed fresh per-call integration. Second, the nonlinear SVD cap is separate from at most 128 pressure-guide SVD attempts and one normal-only Bullet pivot-guide call. Bullet exposes a guide call count, not a hard internal pivot-iteration cap; a total runtime guarantee does not follow. The parent will initially restrict the supplemental fallback to at most 64 rows, after previous stages decline.

The mobility-null relocation records its actual full velocity response. These are floating-point numerical initializations, not body actions. Final mechanical acceptance protects the result even if an initialization is imperfect. No arbitrary-array positive-semidefiniteness certification is performed: the helper assumes the mechanically assembled symmetric mobility matrix supplied by the engine; this review does not claim that it repairs an invalid assembly.

No blocking mechanical gate or failure-output issue remains in the reviewed snapshot. The companion author's captured-system replays provide collision-case evidence; full random-hull trajectory and refinement qualification remains a separate requirement. This optional host-native LAPACK fallback has no WebAssembly portability claim.
